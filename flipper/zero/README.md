# Flipper Zero

## Development

```bash
# Install flipper application on arch
sudo pacman -S qflipper

# Setup development environment
# Use: uFBT - micro Flipper Build Tool
mkdir project
uv init
# ref: https://github.com/flipperdevices/flipperzero-ufbt
uv add ufbt
```
