# Sportstech WRX400

## Allgemein

Vor den Geräten von Sportstech muss gewarnt werden. Ersatzteile sind nur innerhalb der zweijährigen Garantiebestimmungen lieferbar. Einen Tag nach Kaufdatum sind Ersatzteile nicht mehr lieferbar.  
Damit muss jeder selbst entscheiden, ob man den Aufpreis bezahlt um keinen Mehrwert zu erhalten. Die Geräte werden ebenfalls in China produziert und halten die zwei Jahre gerade so.  
Kundenservice gibt es nicht, nur vorgefertigte Textbausteine von einem LLM-Agenten.
