# LandXcape LX790

## Cleaning

Cleaning should be done by using a hand broom, a damp cloth and a spray bottle filled up with warm soap water.

## Configuration

### Change default Start Time

* The default start time is `09:00`
* Press `Start` and `STOP` at the same time until you hear a sound
* The time your press the buttons will be set as the start time

### Change Pin Code

* Press `Start` and `Home` together for five seconds
* The lock will start blinking
* Set the new pin by using the `Start` and `Home` buttons
* Confirm each digit with the `OK` button

### Set Date and Time

* Press `Start` for three seconds
* Set the date and the time by using the `Start` and `Home` button
* Confirm each data with the `OK` button

### Set Working Area

* Press `OK` for three seconds and release it when a clock icon is blinking
* The area is measured via an `A` followed by a number
* Press `Start` or `Home` key to adjust to your number
* The higher the number, the more often the machine will working per week
* Press `OK` to confirm the setting
